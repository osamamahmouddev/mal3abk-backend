# Malabak.Modules.Teams

Bounded context managing football squads, player rosters, tactical formations, invitations, and captaincy rights.

## Key Features
- **Team Management:** Squad creation, crests, home pitch preferences, and member roles (Captain, Vice-Captain, Member).
- **Roster & Lineups:** 5v5, 7v7, and 11v11 tactical formation visual builders.
- **Invitation Workflow:** Phone-based and in-app member invitations with capacity limits.
- **PostgreSQL Schema:** `teams.*`.
